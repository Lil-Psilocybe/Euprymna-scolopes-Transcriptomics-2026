# Euprymna-scolopes-Transcriptomics-2026


This repositiory holds "Additional Information" for Briseno et al. 2026 (in press).

Included here is:
- R script for processing bulk RNASeq data and producing figures from a featureCounts matrix of short-read Illumina sequences mapped to the Euprymna scolopes genome (add sources).
- Juoyter notebook for processing single-nucleus RNASeq data and producing figures from a pre-integrated single-nucleus count matrix generated on Parse BioSciences data visualization suite Trailmaker (add sources).
- Buffer recipes for nuclei extraction
